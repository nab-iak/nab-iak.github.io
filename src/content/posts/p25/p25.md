## 使用倾向得分的逆概率加权法（IPW）
### 权重的计算

- Average Treatment Effect (ATE)  
  $$w_i = \frac{Z_i}{p_{1i}} + \frac{1-Z_i}{1-p_{1i}}$$
- Average Treatment Effect on the Treated (ATT)  
  $$w_i = Z_i + (1-Z_i)\frac{p_{1i}}{1-p_{1i}}$$

- 使用ATE计算权重
```r
dt <- dt %>%
  mutate(wt = if_else(abcix==1,1/ps,1/(1-ps)))
```

### 极端权重值的对应方法
- 方法
	- 重新考虑是否使用倾向得分模型
	- 使用倾向得分进行其他的分析
	- 权重截断（weight truncation）
	- 稳定权重（stabilized weight）

- 权重截断
	- 这里将0.99以上的权重值改为0.99
```r
dt <- dt %>%
	mutate(
		wt_trun = if_else(
			wt > quantile(wt, prob = 0.99),
			quantile(wt, prob = 0.99),
			wt
		)
	)
```

- 稳定权重
	- 在ATE的基础上分别乘以概率的均值  
	  $$w_i = c_1 \frac{Z_i}{p_{1i}} + c_0 \frac{1-Z_i}{1-p_{1i}}$$
```r
dt <- dt %>%
  mutate(c1 = mean(ps), 
         c0 = mean(1-ps),
         wt_stab = if_else(abcix==1,wt*c1,wt*c0))
```

### 对3种加权方式的比较
```r
res <- dt %>%
```

	- 权重统计值
		- `Coef of Var`：变异系数，  
		  衡量权重的相对离散程度；

		  熵值越小，说明权重分布越不均匀
	- 有效样本量（ESS）

### `MatchIt`包检查权重平衡
- `MatchIt`包多用于PSM，  
  也可以通过设置`method = NULL`及`s.weights`来检查权重平衡
- `summary()`之后可以获得评估结果
	- `Means Treated`与`Means Control`：  
	  加权后，处理组和控制组中各个协变量的均值
	- `Std. Mean Diff.`：SMD
	- `Var. Ratio`：方差比
	- `eCDF Mean` \/ `eCDF Max`：  
	  经验累积分布函数（Empirical Cumulative Distribution Function）  
	  的均值差异和最大差异
		- 越接近0越好
	- **`Matched` / `Unmatched` / `Discarded`**:   
	  因为没有执行任何匹配操作，  
	  所以所有数据都被认为是匹配的，没有未匹配或丢弃的数据

```r
library(MatchIt)

wt_tab <- matchit(
```

### 构建倾向得分匹配过的队列
- `matchit()`函数
	- `method`：匹配方法
		- `"nearest"`：最近邻匹配
	- `distance`：观测间得分距离
		- `"mahalanobis"`：马哈拉诺比斯距离 / 马氏距离
	- `estimand`：估计方法
		- `"ATT"`：对于那些接受了abcix治疗的患者，这个治疗到底有多大效果
	- `replace`：是否允许重复匹配

	- `caliper`：  
	  匹配观测间距离的SD阈值；  
	  小于改阈值的观测将被匹配；  
	  例如设置为0.2的情况时，距离小于0.2个SD的观测被匹配

### 使用logit变换的倾向得分
- 如果使用倾向得分的logit变换值，  
  需要在`distance`指定
```r
# 先逻辑回归
ps_model <- glm(
	abcix ~ stent + height + female + diabetic + acutemi + ejecfrac + ves1proc, 
	data = dt, 
	family = binomial(link="logit")
)

# 获得预测的link与response值，
# link值就是logit变换值
dt <- dt %>%
	mutate(
		ps_logit = predict(ps_model, type = "link"),
		ps = predict(ps_model, type = "response")
	)

# 其他都一样，仅修改distance
matched_2 <- matchit(
	abcix ~ stent + height + female + diabetic + acutemi + ejecfrac + ves1proc,
	data = dt,
	method = "nearest",
	# 指定为ps_logit而不是glm
	distance = dt$ps_logit,
	caliper = 0.2,
	std.caliper = TRUE,
	ratio = 1,
	replace = F,
	seed = 42
	)

summary(matched_2)
```
